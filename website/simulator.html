📦 封裝成真實手機 APP 指南

我們採用全球最主流的網球 App 封裝技術 Capacitor，可以將此網頁直接打包為原生 iOS (Xcode) 與 Android (Android Studio) 專案。

步驟 1: 初始化行動端專案
npm init -y npm install @capacitor/core @capacitor/cli npx cap init "AI Tennis Coach" "com.aitennis.coach" --web-dir="."
步驟 2: 加入 Android 與 iOS 原生專案
npm install @capacitor/android @capacitor/ios npx cap add android npx cap add ios
步驟 3: 同步並編譯打包成 APK/IPA
npx cap copy # 開啟 Android Studio 編譯 npx cap open android # 開啟 Xcode 編譯 npx cap open ios

🏗️ 檔案結構與對應

• app.html: 手機 App 主要畫面（包含底欄、AI動畫等）

• simulator.html: 本模擬器控制介面

• index.html / about.html ...: 寬螢幕/平板/電腦專用網頁
